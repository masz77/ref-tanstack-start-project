# React Doctor — known false positives

Patterns below are intentional in this white-label monorepo template. React Doctor
should drop diagnostics matching them; do not "fix" by deleting or rewiring.

## deslop/unused-file — template component library

Every component/hook/util under the following paths is a **ready-to-use template
export**, shipped for downstream projects to import after cloning. Being unimported
in the template's own routes is by design, not dead code. Never delete these to
satisfy `unused-file`.

- `src/components/ui/**` — shadcn/Base UI component library
- `src/components/forms/**` — form field wrappers
- `src/lib/hooks/**` — reusable hooks
- `src/lib/toast.tsx` — toast context/provider API

## deslop/unused-export, deslop/unused-dependency, deslop/unused-dev-dependency

Same rationale: the template deliberately exports symbols (e.g. `src/lib/auth-client.ts`)
and keeps dependencies that downstream projects consume but the template itself may not
yet reference. Verify intent before removing; default to keeping.

## react-doctor/no-static-element-interactions — input-group addon

`InputGroupAddon` in `src/components/ui/input-group.tsx` is a layout wrapper whose
`onClick` only forwards focus to the sibling `<input>` (a click-to-focus affordance,
like clicking a `<label>`), and it bails out when the click lands on a real `<button>`
child. It is not a genuine control. Adding `role="button"` + `tabIndex` would insert a
phantom keyboard tab stop that does nothing useful — keyboard users already reach the
input directly. Leave as-is.

## deslop/circular-dependency — generated route tree

`src/routeTree.gen.ts` is auto-generated by TanStack Router (never hand-edited). Any
cycle it participates in is a generator artifact, not a source defect.
